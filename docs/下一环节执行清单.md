
- Compose 烟测通过。

## 6. 服务器部署

在服务器执行：

```bash
cd /opt/apps
git clone https://github.com/YiyuZh/serenity.git serenity
cd /opt/apps/serenity
cp .env.example .env
chmod 600 .env
```

生成密钥：

```bash
python3 - <<'PY'
import secrets
print("ADMIN_PASSWORD=" + secrets.token_urlsafe(24))
print("JWT_SECRET=" + secrets.token_urlsafe(48))
print("POSTGRES_PASSWORD=" + secrets.token_urlsafe(24))
PY
```

把生成值写入 `.env`，再补 X、DeepSeek、飞书、COS 配置。

## 7. 服务器启动

```bash
docker network ls | grep shared_gateway || docker network create shared_gateway
docker compose config
docker compose up -d --build
docker compose ps
curl -i http://127.0.0.1:8000/api/health
```

## 8. Caddy 接入

把以下站点块加入现有 Caddyfile：

```caddy
serenity.zenithy.art {
    import common_site

    @serenity_api path /api/*
    handle @serenity_api {
        reverse_proxy serenity-backend:8000
    }

    handle {
        reverse_proxy serenity-frontend:80
    }
}
```

验证：

```bash
docker compose exec caddy caddy fmt --overwrite /etc/caddy/Caddyfile
docker compose exec caddy caddy validate --config /etc/caddy/Caddyfile
docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile
curl -i https://serenity.zenithy.art/api/health
```
