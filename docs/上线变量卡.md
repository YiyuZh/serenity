## 2.1 国内构建镜像变量

官方默认值适合 GitHub Actions 或海外网络。腾讯云国内服务器如果拉 Docker Hub 或安装依赖超时，可以在 `.env` 里切换为下面这组值：

```bash
PYTHON_IMAGE=docker.m.daocloud.io/library/python:3.11-slim
NODE_IMAGE=docker.m.daocloud.io/library/node:22-alpine
NGINX_IMAGE=docker.m.daocloud.io/library/nginx:1.27-alpine
APT_MIRROR_HOST=mirrors.tuna.tsinghua.edu.cn
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
PIP_EXTRA_INDEX_URL=
PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn
NPM_REGISTRY=https://registry.npmmirror.com
```

如果某个镜像站临时不可用，把对应变量改回官方默认值或换成服务器可访问的企业镜像源。

## 3. Caddy 网关

| 项 | 值 |
|---|---|
| 本地参考项目 | `D:\apps\hiremate` |
| 参考 Caddyfile | `D:\apps\hiremate\Caddyfile` |
| 服务器 Caddyfile 常见路径 | `/opt/apps/hiremate/Caddyfile` |
| Serenity API 路由 | `/api/*` -> `serenity-backend:8000` |
| Serenity 前端路由 | `/*` -> `serenity-frontend:80` |

建议站点块：

```caddy
serenity.zenithy.art {
    import common_site

    @serenity_api path /api/*
    handle @serenity_api {
        reverse_proxy serenity-backend:8000
    }

    handle {
        reverse_proxy serenity-frontend:80
    }
}
```

## 5. 服务器生成密钥命令

在服务器执行：

```bash
python3 - <<'PY'
import secrets
print("ADMIN_PASSWORD=" + secrets.token_urlsafe(24))
print("JWT_SECRET=" + secrets.token_urlsafe(48))
print("POSTGRES_PASSWORD=" + secrets.token_urlsafe(24))
PY
```

复制输出到服务器 `/opt/apps/serenity/.env`，不要提交到 Git。
